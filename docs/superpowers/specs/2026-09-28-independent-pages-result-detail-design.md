# 独立登录、视频工作台与结果详情页设计

日期：2026-09-28

## 目标

将现有同一文档内切换登录区和工作区的实现拆分为三个职责明确的页面，使登录体验真正独立、生成任务排布稳定，并让每个任务拥有可直接访问的结果详情界面。

本轮只调整登录、工作台任务呈现和结果查看流程。保留现有项目、图片上传、可灵 OAuth、视频生成、任务恢复和固定生成舞台能力，不扩展下载、删除、重试或编辑任务等功能。

## 页面与路由

### `/login`

- 独立登录文档，不包含工作台 DOM。
- 保留 MotionSites 循环视频背景及海报回退。
- 登录卡使用深黑色磨砂玻璃视觉，前景文字保持清晰可读。
- 登录成功后使用替换式导航进入 `/workspace`，防止浏览器返回到已登录表单。
- 已登录用户访问该地址时跳转到 `/workspace`。

### `/workspace`

- 独立工作台文档，不包含登录表单。
- 保留一级项目管理、文生视频、图生视频、参考图上传、账户点数、MCP 状态和退出登录。
- 页面主要区域分为生成参数、当前任务舞台和历史任务列表，避免状态和结果相互覆盖。
- 未登录访问时由服务端文档路由跳转到 `/login`。

### `/projects/:projectId/results/:taskId`

- 独立任务详情文档，以项目和任务标识建立稳定深链接。
- 已完成任务显示视频播放器和任务参数。
- 生成中任务显示固定的渐变生成状态和“生成中”，只有服务端提供真实进度时才显示百分比。
- 失败或状态未知的任务显示稳定的状态说明，不渲染空播放器。
- 提供返回所属项目工作台的明确入口。
- 未登录访问时跳转到 `/login`。

### `/`

- 已登录时跳转到 `/workspace`。
- 未登录时跳转到 `/login`。

可灵 OAuth 回调成功后跳转到 `/workspace?authorized=1`。

## 工作台信息架构

### 生成参数区

继续支持文生视频和图生视频模式，包括提示词、参考图、模型、分辨率、时长和画幅。参考图上传成功后继续显示自适应预览与文件信息。

### 当前任务舞台

- 当前任务区域拥有固定尺寸和固定定位上下文，状态动画不会随任务列表或文字高度漂移。
- 排队或生成时在舞台中央显示渐变动画。
- 没有真实百分比时只显示“生成中”，不推算或伪造百分比。
- 服务端返回真实百分比时，百分比显示在动画下方。
- 任务完成后，播放器替换生成动画，同时保留“查看结果”入口。
- 新任务开始后，上一个已完成任务回到下方历史列表，不继续占用当前任务舞台。

### 历史任务列表

- 每个任务使用独立行或卡片，至少显示状态、模式、创建时间和主要参数摘要。
- 生成中任务显示状态，不重复运行大型舞台动画。
- 已完成且存在可播放视频的任务显示“查看结果”。
- 失败或状态未知的任务显示“查看详情”，详情页呈现其真实状态。
- 任务顺序保持稳定，以最近更新或创建的任务优先。

## 结果详情内容

结果页展示以下经过清理的任务数据：

- 视频结果；
- 任务状态；
- 文生视频或图生视频模式；
- 提示词；
- 模型；
- 分辨率；
- 视频时长；
- 画幅；
- 创建时间与更新时间；
- 所属项目及返回入口。

结果页不展示幂等键、服务端凭据、OAuth 信息或原始供应商机密字段。

## 数据接口

新增需要登录的只读接口：

`GET /api/projects/:projectId/tasks/:taskId`

接口必须同时验证当前用户拥有该项目，并验证任务属于该项目。响应返回供详情页使用的清理后数据对象，不要求详情页读取整个项目工作区再自行搜索任务。

既有任务提交、轮询、恢复和项目工作区接口保持兼容。API 未授权响应继续使用 JSON `401`；只有 HTML 文档路由执行页面跳转。

## 静态资源与模块边界

页面拆分为：

- `login.html` 与登录入口脚本；
- `workspace.html` 与工作台入口脚本；
- `result.html` 与结果详情入口脚本。

可复用的任务状态、结果 URL 提取和安全文本呈现逻辑放入共享模块，避免工作台和详情页对状态产生不同解释。构建流程需要指纹化三个页面使用的脚本，并把全部页面及依赖资源写入站点资产映射。

## 错误处理

- 登录失败在登录卡内显示服务端返回的安全错误信息。
- 详情任务不存在、项目不匹配或无权限时显示明确的不可访问状态，不泄露其他项目信息。
- 已完成任务没有可用视频 URL 时显示“结果暂不可播放”，而不是空白区域。
- 网络中断时保留当前界面内容，并提供重新加载入口。
- 可灵状态异常沿用当前恢复和轮询策略，页面刷新后可重新取得真实任务状态。

## 测试与验收

### 路由与鉴权

- 匿名访问 `/`、`/workspace` 和结果详情路由时行为正确。
- 已登录访问 `/` 和 `/login` 时进入工作台。
- OAuth 回调进入工作台。
- API 的 `401` 仍为 JSON，不被页面重定向替代。

### 页面隔离

- 登录页面不包含工作台结构。
- 工作台页面不包含登录表单。
- 结果页可以通过深链接独立加载。

### 任务详情安全

- 用户只能读取自己项目中的任务。
- 任务与项目不匹配时不返回任务数据。
- 响应不包含秘密字段。

### 状态呈现

- 无真实进度时不显示百分比。
- 有真实进度时百分比正确显示且位置固定。
- 完成后视频替换进度动画。
- 新任务启动后，上一次完成结果出现在历史列表。
- 完成、生成中、失败和未知状态的详情页均有明确界面。

### 发布前验证

运行完整自动化测试和生产构建，并在桌面与手机视口人工检查登录页、工作台、任务列表和结果详情页。验证通过后再发布站点新版本。

## 不在本轮范围

- 视频下载；
- 删除任务或结果；
- 重新生成或复制参数；
- 编辑已提交任务；
- 多级项目结构；
- 更换存储供应商；
- 修改可灵计费或点数逻辑。
