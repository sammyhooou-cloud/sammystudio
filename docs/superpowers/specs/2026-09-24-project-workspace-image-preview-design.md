# 一级项目工作区与参考图预览设计

## 目标

为视频生成工作台增加一级项目管理，让每个项目独立保存参考图片、生成参数、生成任务与生成视频。同时完善参考图上传后的界面反馈，在桌面端和手机端自适应显示图片与文件信息。

## 范围

本次包含：

- 新建、重命名和切换一级项目。
- 为已有数据提供“未分类项目”作为默认归属。
- 每个项目独立保存参考图片、生成参数、任务状态和生成结果。
- 上传参考图后显示缩略图、文件名、格式、大小和上传状态。
- 支持重新选择或移除当前参考图。
- 桌面与手机端响应式布局。

本次不包含：

- 子文件夹或多级目录。
- 删除项目。
- 跨项目批量移动素材或任务。
- 团队协作、权限或分享。

## 信息架构

工作台由“项目导航”和“当前项目工作区”组成。

- 桌面端：项目导航作为左侧可折叠侧栏，当前项目工作区保留视频生成表单和结果区域。
- 手机端：项目导航变为抽屉，通过顶部项目入口打开。
- 当前项目名称在工作区顶部明确显示。
- 首次进入且没有项目时自动创建“未分类项目”。

## 项目模型

项目包含稳定 ID、名称、创建时间和更新时间。参考素材、生成任务与参数快照都通过项目 ID 归属。

项目名称不能为空，首尾空格会被移除。新项目创建后自动成为当前项目。重命名只修改名称，不影响已有素材和任务。

## 数据流

1. 用户登录后加载项目列表。
2. 系统恢复最近选择的项目；若不存在，则选择列表中的第一个项目。
3. 用户切换项目后，界面重新加载该项目的参考素材、最近参数和任务记录。
4. 上传参考图时，客户端先显示本地缩略图与上传中状态。
5. 服务端将文件写入对象存储，并记录项目归属与文件元数据。
6. 上传成功后，客户端保存上传 ID，显示成功状态，并允许重新选择或移除。
7. 提交生成任务时，项目 ID、当前参数和参考图 ID 一并写入任务记录。

## 参考图预览

预览使用 `object-fit: contain` 保持原始比例，不裁切主体。预览容器设置合理的最大高度，横图、竖图和方图都在可用区域内完整显示。

预览区显示：

- 图片缩略图。
- 文件名。
- MIME 格式的友好名称。
- 文件大小。
- 上传中、上传成功或上传失败状态。
- “重新选择”和“移除”操作。

桌面端采用缩略图与信息横向排列；窄屏下改为上下排列，操作按钮保持足够的触控尺寸。

## 接口与存储

新增项目接口：

- `GET /api/projects`：读取项目列表与当前项目。
- `POST /api/projects`：创建项目。
- `PATCH /api/projects/:id`：重命名项目。
- `GET /api/projects/:id/workspace`：读取项目素材、最近参数和任务。

现有上传与任务接口增加 `projectId`。服务端必须校验项目存在，且不得接受客户端指定的任意对象存储路径。

数据库新增项目表，并为素材和任务记录增加项目外键。现有无项目数据迁移到“未分类项目”。图片二进制继续存入对象存储，数据库只保存对象键与必要元数据。

## 错误处理

- 项目加载失败：保留当前界面并显示可重试提示。
- 图片类型或大小不符合要求：不上传，并在预览区显示明确错误。
- 上传失败：保留本地缩略图和失败状态，允许重试或重新选择。
- 切换项目时存在未提交表单：保留各项目最近一次本地表单状态，避免误丢输入。
- 项目不存在：回退到第一个可用项目；没有项目时创建“未分类项目”。

## 测试与验收

- 首次进入自动获得“未分类项目”。
- 新建与重命名项目后，项目列表和当前项目同步更新。
- 不同项目的参考图、参数和任务互不混用。
- 上传图片后立即显示缩略图、文件名、格式、大小和状态。
- 横图、竖图、方图均完整显示且不变形。
- 重新选择会替换当前参考图；移除后表单恢复未上传状态。
- 上传失败可恢复，不会留下可提交的无效上传 ID。
- 桌面侧栏与手机抽屉均可切换项目，手机预览不会横向溢出。
- 原有登录、MCP 状态、参数选择和任务提交测试保持通过。
