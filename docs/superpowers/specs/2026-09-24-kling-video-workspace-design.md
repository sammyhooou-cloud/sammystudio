# 可灵视频生成工作区设计

## 目标

将当前登录节点升级为可真实使用的云端工作台。管理员登录后进入第一个应用板块“视频生成”，通过可灵 MCP 完成 OAuth 授权、文生视频、图生视频、任务查询和账户点数余额读取。

本节点只实现视频生成板块，不加入图片制作、账号管理或其他应用。

## 系统边界

- 浏览器负责界面、参数编辑、参考图选择、授权跳转和任务状态展示。
- 网站服务端负责管理员认证、可灵 OAuth、MCP 通信、令牌刷新、文件转存和任务持久化。
- 可灵访问令牌、刷新令牌和管理员密码均不得进入浏览器代码、日志或 Git。
- 当前本机 Codex 的可灵授权仅用于开发验证；网站使用独立的 OAuth 会话。

## 页面结构

### 登录

保留当前登录视觉，但改为服务端认证。用户名和密码通过 HTTPS 提交；服务端使用环境变量中的密码摘要校验，并签发 `HttpOnly`、`Secure`、`SameSite=Lax` 会话 Cookie。

### 视频生成工作区

登录成功后切换为全屏工作区：

- 顶部：视频生成标题、MCP 红/绿状态灯、会员状态、点数余额、余额刷新按钮和最后更新时间。
- 左侧主表单：文生视频/图生视频模式、模型、提示词、分辨率、时长、画幅和生成数量。
- 图生视频模式额外显示参考图上传区；首版支持一张首帧图。
- 右侧任务区：空状态、排队、生成中、成功和失败；成功后显示视频预览与下载入口。
- 移动端改为纵向排列，参数表单优先，任务结果随后。

## 模型与参数

服务端通过 MCP `who_am_i` 读取实时模型能力，前端不硬编码超出模型能力的选项。

- 模式：文生视频、图生视频。
- 模型：展示 MCP 返回的可用视频模型。
- 分辨率：720p、1080p；仅在模型支持且账户有权限时显示 4K。
- 时长：根据模型限制展示 3–15 秒中的可选值。
- 画幅：16:9、9:16、1:1。
- 参考图：首帧一张，上传前校验为图片且限制文件大小。
- 提示词：文生视频必填；图生视频可按模型规则选填或必填。

模式或模型变化时，页面自动修正已失效的分辨率、时长和画幅值，并以简短说明提示用户。

## OAuth 与 MCP

可灵公开元数据确认以下端点：

- 资源：`https://klingai.com/mcp`
- 授权服务器：`https://klingai.com/auth`
- 授权：`https://klingai.com/auth/authorize`
- 令牌：`https://klingai.com/auth/token`
- 动态注册：`https://klingai.com/auth/register`
- 撤销：`https://klingai.com/auth/revoke`

OAuth 使用授权码流程和 PKCE `S256`。服务端生成并保存短期 `state`、`code_verifier` 和回调上下文；回调必须校验 `state`。令牌使用服务端密钥加密后持久化，过期前通过刷新令牌更新。

MCP 调用顺序：

1. OAuth 授权成功。
2. 初始化 MCP 会话并读取工具列表。
3. 调用 `who_am_i` 验证身份与模型能力。
4. 调用 `query_membership_and_credits` 读取会员和点数。
5. 文生视频调用 `text_to_video`。
6. 图生视频先使用 `file_upload`，再调用 `image_to_video`。
7. 使用 `query_tasks` 查询任务状态，直到成功或失败。

## 连接状态与余额

- 绿灯：最近一次 `who_am_i` 成功且令牌有效。
- 红灯：未授权、刷新失败、MCP 超时或身份验证失败。
- 页面进入、OAuth 回调完成及任务提交成功后刷新会员与点数。
- 用户可手动刷新余额；刷新按钮有加载和防重复状态。
- 查询失败时显示“余额暂不可用”，绝不将未知余额显示为零。
- 余额响应不写入公开日志；数据库可保存最近一次余额及时间，用于短时缓存。

## 云端存储

测试阶段使用站点平台提供的对象存储和数据库，不使用浏览器本地存储保存业务数据。

- 对象存储保存参考图和需要长期保留的视频结果。
- 数据库保存管理员会话、OAuth 客户端记录、加密令牌、生成任务、存储对象键和状态时间线。
- 上传使用随机对象键，保留 MIME 类型和大小，不保留用户原始文件路径。
- 未来迁移到百度智能云 BOS 时，通过存储适配层替换对象存储实现；业务层不依赖具体厂商。
- 百度网盘不作为本节点的网站对象存储。

## 服务端接口

- `POST /api/session`：管理员登录。
- `DELETE /api/session`：退出登录。
- `GET /api/kling/status`：返回 MCP 状态、会员、余额、模型能力和更新时间。
- `GET /api/kling/oauth/start`：创建 PKCE 授权流程并跳转。
- `GET /api/kling/oauth/callback`：校验回调并保存加密令牌。
- `POST /api/uploads`：上传并校验参考图。
- `POST /api/video/tasks`：校验参数并提交真实 MCP 任务。
- `GET /api/video/tasks/:id`：返回持久化任务及最新 MCP 状态。

所有接口除 OAuth 回调外均要求管理员会话；改变状态的请求校验同源来源并使用严格 JSON/文件大小限制。

## 错误处理

- 登录失败使用统一错误，避免泄漏用户名是否存在。
- OAuth 被拒绝、`state` 不匹配、令牌交换失败和刷新失败分别记录安全事件，并向前端返回可恢复提示。
- MCP 超时不会自动重复创建生成任务，避免重复扣点。
- 提交成功但响应中断时，使用幂等键和任务记录恢复查询。
- 上传失败时删除未被任务引用的临时对象。
- 余额不足时阻止提交并提示用户前往可灵处理额度。

## 验证范围

- 管理员登录成功与失败、会话保护和退出。
- OAuth PKCE 参数、回调 `state` 校验、令牌加密和刷新路径。
- MCP 绿灯、红灯及恢复。
- 余额成功、加载、失败和任务后刷新。
- 文生视频参数映射、图生视频上传与参数映射。
- 不同模型下分辨率、时长和画幅联动。
- 任务状态轮询、幂等提交和错误显示。
- 桌面与移动端视觉检查。
- 生产构建、云端存储读写和私有部署检查。

## 非目标

- 多管理员、用户注册、找回密码和权限分级。
- 图片生成、账号管理、MCP 管理中心或其他应用板块。
- 百度网盘/BOS 正式接入。
- 批量队列、多人协作和复杂资产库。
